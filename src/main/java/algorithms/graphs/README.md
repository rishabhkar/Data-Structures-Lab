# Graphs (algorithms track)

## Track

Algorithms track: `algorithms`

## What this category covers

Graph algorithms: shortest paths, spanning trees, ordering, and search.

## Algorithms in this category

- `astar/` — `AStar` (see its README).
- `bellmanford/` — `BellmanFord` (see its README).
- `dijkstra/` — `Dijkstra` (see its README).
- `floydwarshall/` — `FloydWarshall` (see its README).
- `kruskal/` — `Kruskal` (see its README).
- `prim/` — `Prim` (see its README).
- `topologicalsort/` — `TopologicalSort` (see its README).

## Layout

Each algorithm has its own folder containing a blank class, a `<Algorithm>Main` runner, and a README.
Implement each algorithm manually, wire a quick example into its runner to try it out, and add tests under the mirrored `src/test/java/...` path.
