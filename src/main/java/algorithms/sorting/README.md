# Sorting (algorithms track)

## Track

Algorithms track: `algorithms`

## What this category covers

Comparison and non-comparison sorting algorithms.

## Algorithms in this category

- `bubblesort/` — `BubbleSort` (see its README).
- `countingsort/` — `CountingSort` (see its README).
- `heapsort/` — `HeapSort` (see its README).
- `insertionsort/` — `InsertionSort` (see its README).
- `mergesort/` — `MergeSort` (see its README).
- `quicksort/` — `QuickSort` (see its README).
- `radixsort/` — `RadixSort` (see its README).
- `selectionsort/` — `SelectionSort` (see its README).

## Layout

Each algorithm has its own folder containing a blank class, a `<Algorithm>Main` runner, and a README.
Implement each algorithm manually, wire a quick example into its runner to try it out, and add tests under the mirrored `src/test/java/...` path.
