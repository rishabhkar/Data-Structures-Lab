# Dynamicprogramming (algorithms track)

## Track

Algorithms track: `algorithms`

## What this category covers

Classic dynamic-programming problems.

## Algorithms in this category

- `coinchange/` — `CoinChange` (see its README).
- `editdistance/` — `EditDistance` (see its README).
- `knapsack/` — `Knapsack` (see its README).
- `longestcommonsubsequence/` — `LongestCommonSubsequence` (see its README).
- `longestincreasingsubsequence/` — `LongestIncreasingSubsequence` (see its README).

## Layout

Each algorithm has its own folder containing a blank class, a `<Algorithm>Main` runner, and a README.
Implement each algorithm manually, wire a quick example into its runner to try it out, and add tests under the mirrored `src/test/java/...` path.
