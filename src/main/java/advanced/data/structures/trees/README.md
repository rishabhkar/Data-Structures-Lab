# Trees (advanced track)

## Track

Advanced implementation track: `advanced-data-structures`

## What this category covers

Advanced and self-balancing tree structures (AVL, red-black, tries, and range trees).

## Structures in this category

- `avltree/` — `AVLTree` (see its README).
- `btree/` — `BTree` (see its README).
- `fenwicktree/` — `FenwickTree` (see its README).
- `redblacktree/` — `RedBlackTree` (see its README).
- `segmenttree/` — `SegmentTree` (see its README).
- `trie/` — `Trie` (see its README).

## Layout

Each structure has its own folder containing a blank class, a `<Class>Main` runner, and a README.
Implement each structure manually and add tests under the mirrored `src/test/java/...` path.
