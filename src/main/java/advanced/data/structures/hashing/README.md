# Hashing (advanced track)

## Track

Advanced implementation track: `advanced-data-structures`

## What this category covers

Hash-table structures and collision-resolution strategies.

## Structures in this category

- `openaddressing/` — `OpenAddressingHashTable` (see its README).
- `separatechaining/` — `SeparateChainingHashTable` (see its README).

## Layout

Each structure has its own folder containing a blank class, a `<Class>Main` runner, and a README.
Implement each structure manually and add tests under the mirrored `src/test/java/...` path.
